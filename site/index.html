nsh-qr-code

Decode and generate QR codes for NSH apps.

Status: in progress. Nothing here is verified until a CI run on master passes a test for it. This page is a status page, not a demo.

Planned approach and edge cases: docs/brief.md.

Feature status: docs/parity.md.

Source: SuperNSH/qr-code.

Parity

Where each public API of the two references lands in this library: mobile_scanner (Flutter) and the barcode scanner of react-native-vision-camera, package react-native-vision-camera-barcode-scanner. Both are cloned read-only under .refs/; every API named below was read there.

  • implemented — awaiting first passing CI run — the contract names the feature, but no CI run on master has passed a test for it, so the row is unverified.
  • not ours — camera controls belong to the camera repo (nsh-camera) — a camera control this library deliberately lacks; SuperNSH/nsh-camera owns it.
  • out of scope: QR only — rides on multi-symbology support this library never has.
  • no equivalent — a reference state our design cannot express.

Rust names are snake_case in crates/nsh-qr-code; TS names are the camelCase mirrors in packages/nsh-qr-code (scan, stop, cameraPermission, requestCameraPermission, decodeFrame, generate, toSvg, memoryBackend, rustBackend, useQrScanner).
